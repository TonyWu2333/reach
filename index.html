你的 Agent
清单 收藏 协作 知识库 Skill 工作流

AI 已经学会了思考，却还碰不到你的生活。你的日程、收藏和笔记，散落在一个个互不相通的 App 里，它看不见，也够不着。

可及想做的，是给 agent 长出手。每一个可及 App 都是一只触手，伸进生活的一个角落；所有触手都连回同一个大脑，也就是你正在用的那个 agent。

这也是「可及」这个名字的由来：触手可及。

我们相信，好的工具应该让能力伸手可得，而不是把人困在原地。人、agent 与工具之间，不再有墙。

打开，看今天，

农历日历、四象限、打卡、一句话添加。轻快好看的日程 App，你的 agent 也能直接看和改你的任务。

查看源码 安装说明 ↗

贴合国内的日历

月视图直接显示农历、节气和节日，法定节假日标「休」，调休标「班」。

四象限

每个任务都能放进「重要 × 紧急」四象限，长按拖动就能调整优先级。

一句话添加

输入「明天下午3点开会」就是明天 15:00；「每周五晚上8点 羽毛球」就是每周重复。

打卡

重复任务集中在一页，按规则分组，带进度环和连续天数。

子任务与提醒

子任务也是完整的任务；本地精确提醒，提前排好未来 30 天。

手势与撤销

右滑完成，左滑推迟、放弃或删除，误操作随时撤销。

我今天有什么事？

planner today

[ ] 07:00 晨跑 5 公里  (每天)  #a1b2
[ ] 10:00 产品周会  (重要且紧急)  #c3d4
[ ] 15:30 review 设计稿  (重要不紧急)  #e5f6
[ ] 续费域名  (已过期 · 昨天)  #0a1b

今天有 3 件事，另外「续费域名」昨天过期了，要挪到今天吗？

挪到今天下午 4 点，再加个每周五晚上 8 点打羽毛球

planner edit 0a1b --date 今天 --time 16:00

planner add 每周五晚上8点 羽毛球

好了。「续费域名」改到今天 16:00；新增「羽毛球」，每周五 20:00 重复。

  1. 1

    运行同步服务器

    单文件、零依赖的 Node 服务，数据就是一个 JSON 文件。启动后打印一个连接码。

    node planner-server.mjs
  2. 2

    手机粘贴连接码

    在 App 的「我的 → 同步与 Agent」里打开开关，粘贴连接码。

    http://主机:端口#令牌
  3. 3

    把 skill 装给 agent

    把 skill 文件夹放进 agent 的 skills 目录，登录一次就好。

    ~/.claude/skills/planner
